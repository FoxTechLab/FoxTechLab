## 🚀 Current Project

### FoxMeasureStudio

A measurement monitoring, data logging and analysis application being developed for Fluke 287/289 digital multimeters.

**Development goals:**
- Real-time measurement monitoring
- USB-IR communication
- Data logging and visualization
- Measurement history and graph analysis
- CSV and spreadsheet export
- Windows support and future Linux compatibility

*Project under active development.*
